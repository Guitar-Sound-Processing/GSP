
# GSP Application Software

## Description 

The Guitar Sound Processing can be remotely operated using an Android application software freely available. It runs on Android 10 and above, but it is expected that it can also work on older versions. The software was generated with Gemini's AI helping, basicaly to provide kotlin coding. The software is still in progress but version 1.0 is already working with minor bugs. Some new improvements may be soon available, mainly in the Expression Pedal algorithm. Currently the app software is available for download only at github's GSP page, although in future versions it can be also available in Google Play Store.

The application software is organized in 4 levels (see figure below):
- Effect and Preset Editor
- Chain (Rig) Editor
- Song Editor
- Playlist Editor and on stage performance
